# MeshCut

**English**

MeshCut lets you cut the world with a lightsaber or a laser gun, and what you cut behaves like real matter. Blocks are sliced along any angle (not just on the block grid), burnt open with glowing edges, and left as smooth cut surfaces. Whatever is no longer attached to the ground comes loose as its own physical piece, which you can push, pick up and throw. Entities can be cut too: a mob falls apart into limbs held together by ragdoll joints. Built on [Sable](https://modrinth.com/mod/sable) physics; optional support for AnvilCraft lasers, and for GeckoLib and Citadel models when cutting mobs.
